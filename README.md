# 🚀 MX-Optimization Suite (MX-Optimizate) v1.0

**MX-Optimization** — это ультимативный, бескомпромиссный комплекс низкоуровневой настройки операционной системы Windows 10/11, разработанный специально для **Counter-Strike 2 игроков** и активных пользователей соревновательной платформы **FACEIT**. 

Этот проект разработан для тотального уничтожения инпут-лага (Input Lag), стабилизации времени кадра (Frametime), устранения микрофризов и выжимания максимального FPS из вашего железа. Программа перестраивает Windows из многозадачной офисной среды в специализированную игровую станцию.

---

## 🔬 Что конкретно делает MX-Optimization в вашей системе?

Программа глубоко вмешивается в работу операционной системы, изменяя ключевые параметры планировщика Windows, сетевого стека и распределения ресурсов:

### 1. Тотальный деблоатинг и вырезание фоновой активности
Windows по умолчанию тратит до 20-30% ресурсов процессора и диска на сбор аналитики и работу фоновых приложений. **MX-Optimization** жестко пресекает это:
*   **Уничтожение телеметрии на уровне ядра:** Блокируются службы сбора данных `DiagTrack` (Universal Telemetry Client), `WPP Recorder`, `Device Census` и программа улучшения качества ПО (CEIP). Это освобождает циклы процессора, которые раньше тратились на отправку отчетов в Microsoft.
*   **Отключение фоновых UWP-служб:** Замораживается фоновая работа встроенных приложений (включая принудительное завершение процессов Microsoft Edge и синхронизации OneDrive). Ваши оперативная память и кэш процессора полностью отдаются игре.
*   **Очистка Планировщика задач:** Отключается более 30 скрытых вредоносных задач в `Task Scheduler` (связанных с диагностикой дисков, памяти и сетевым трекингом), которые любят запускаться прямо во время матча.

### 2. Изменение квантов времени CPU и аппаратных приоритетов
*   **Твик Win32PrioritySeparation (Значение 26 Hex / 38 Dec):** Это ключевой киберспортивный твик. Он изменяет приоритеты планировщика Windows, выделяя максимальные и фиксированные кванты времени процессора для активного окна. Когда запущена CS2, все фоновые процессы принудительно сдвигаются на задний план, гарантируя стабильный FPS без просадок.
*   **Управление питанием ядра и PCIe:** Активируется скрытая схема питания *Ultimate Performance* (Максимальная производительность). Она полностью отключает парковку ядер CPU (все ядра всегда активны и готовы к нагрузке) и блокирует энергосбережение линий PCIe (`ASPM`), убирая задержки при передаче данных между видеокартой, процессором и NVMe-накопителем.

### 3. Оптимизация мыши: Идеальный линейный трекинг (1-к-1)
*   Windows по умолчанию использует алгоритмы сглаживания курсора, которые искажают реальное движение мыши (акселерация). 
*   **MX-Optimizate** принудительно обнуляет параметры `MouseSpeed`, `MouseThreshold1`, `MouseThreshold2` и полностью перезаписывает таблицы масштабирования `SmoothMouseXCurve` и `SmoothMouseYCurve`. Отклик сенсора становится идеально линейным. Сколько миллиметров вы физически провели по коврику — ровно на столько пикселей сдвинулся ваш прицел. Чистая мышечная память.

### 4. Стабилизация сетевого стека под киберспорт (Anti-Lag Network)
*   **Отключение алгоритма Нагла (`TCPNoDelay` и `TCPAckFrequency` = 1):** Windows по умолчанию буферизирует (задерживает) мелкие пакеты данных, чтобы отправить их одним большим блоком. Для CS2 это критично, так как вызывает задержку регистрации попаданий. Наш твик заставляет систему отправлять каждый пакет мгновенно. Пинг становится стабильнее, а регистрация хитов (hitreg) — идеальной.
*   **Снятие лимита QoS:** Windows резервирует до 20% пропускной способности сети под свои нужды. Скрипт обнуляет этот лимит (`NonBestEffortLimit = 0`), отдавая 100% интернет-канала игровому трафику.

### 5. Ликвидация статтеров через кэш шейдеров
*   Одной из главных болячек CS2 является внезапный фриз (статтер) при появлении противника, взрыве гранаты или выстреле из мухи/авика. Это происходит из-за конфликта устаревшего кэша шейдеров. Модуль клинера принудительно очищает **DirectX Shader Cache**, заставляя видеокарту перекомпилировать шейдеры начисто, что возвращает игре идеальную плавность.

## 🛡️ Безопасность для FACEIT Anti-Cheat

Самая важная архитектурная особенность **MX-Optimization** — это полная безопасность при игре на FACEIT:
*   Античит FACEIT работает на уровне ядра (`faceit.sys`) и мгновенно блокирует систему, если повреждены цифровые подписи драйверов или отключена подсистема шифрования.
*   Многие сторонние твикеры ломают эти службы, из-за чего FACEIT AC выдает ошибку. **MX-Optimizate** разработан с хирургической точностью: все компоненты шифрования, изоляции ядра (`Code Integrity`) и проверки сертификатов остаются **тронутыми на 100%**. Отключается только бесполезный системный мусор.

## ⚠️ Предосторожности (ВНИМАТЕЛЬНО К ПРОЧТЕНИЮ)

*   **Делайте бэкап:** Всегда используйте модуль резервного копирования в папке `06_Windows_Restore_Functions` перед применением глубоких настроек.
*   **Специфика EXTREME пресета:** Пресет Максимум FPS полностью отключает Защитник Windows и Центр обновлений Windows. Используйте его только на строго игровых системах. Если вам нужен встроенный антивирус для безопасного серфинга в интернете, используйте пресет **PRO_GAMING** — он оставляет Защитник включенным, но убирает остальной мусор.
*   **Офисные компоненты:** Пресеты PRO и EXTREME отключают службы принтеров (печать) и Xbox-сервисы. Если ПК используется для работы с офисной техникой, используйте пресеты **BASIC** или **ADVANCED**.

## 🚀 Инструкция по запуску
1.  Перейдите во вкладку **Releases** с правой стороны и скачайте актуальный архив проекта `MX-Optimization.zip`.
2.  Распакуйте содержимое архива в папку на вашем Рабочем столе.
3.  Нажмите правой кнопкой мыши по файлу `MX_Optimizer_Menu.bat` и выберите **«Запуск от имени Администратора»** (иначе твики реестра HKLM не применятся).
4.  Используйте интерактивное меню для навигации по пресетам.
