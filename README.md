# MX-Optimization

# 🚀 MX-Optimization Suite v1.0

Комплексный открытый оптимизатор операционной системы Windows 10/11, разработанный специально для **киберспортсменов и игроков в CS2**. Проект ориентирован на достижение максимального FPS, минимизацию задержки ввода (Input Lag) и сохранение полной стабильности системы при игре на платформе **FACEIT**.

## 🛠 Ключевые особенности и архитектура
*   **FACEIT Anti-Cheat Safe:** Все твики и оптимизации служб протестированы и не вызывают конфликтов, блокировок или крашей клиента FACEIT AC.
*   **Абсолютный ноль акселерации:** Уникальные .reg скрипты (линейный отклик 1:1) для идеального трекинга мыши.
*   **Борьба со статтерами:** Модуль очистки кэша DirectX Shader Cache для устранения микрофризов во время динамических сцен.
*   **Низкий пинг:** Интеграция сетевых настроек реестра (TCPNoDelay) для стабилизации пакетов.

## 📁 Структура проекта
1.  `01_Optimization_Presets` — Четыре уровня настройки системы (Basic, Advanced, PRO, Extreme).
2.  `02_Mouse_Acceleration_Kill` — Жесткое удаление сглаживания и акселерации курсора на уровне ядра.
3.  `03_Global_System_Cleaner` — Глубокий клинер мусора и кэша.
4.  `04_Internet_Optimization` — Твики для уменьшения сетевых задержек.
5.  `05_System_Benchmark` — Проверка вычислительной мощности ПК и стабильности таймингов.
6.  `06_Windows_Restore_Functions` — Панель отката изменений и проверки целостности файлов.

## 🚀 Инструкция по запуску
1. Скачайте архив проекта во вкладке **Releases** или склонируйте репозиторий.
2. Распакуйте папку на рабочий стол.
3. Откройте папку и запустите файл `MX_Optimizer_Menu.bat` **от имени Администратора**.
4. Выберите необходимый модуль в интерактивном меню.
